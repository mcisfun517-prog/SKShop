# 自定义骷髅商人商店 (SKShop)

- 作者：百事#0 基于CNPCShop
- 本插件用于 **替换骷髅商人（Skeleton Merchant）** 的商店内容，让您可以自由定制出售的物品、价格、前缀以及显示条件。

## 主要作用
- **完全自定义商品**：可任意添加、删除或修改骷髅商人出售的物品，支持设置物品数量、前缀和价格（铜/银/金/铂）。
- **灵活的条件限制**：每个商品可设置独立的显示条件，满足条件时才在商店中显示。支持条件包括：
  - 击败特定 Boss（如史莱姆王、克苏鲁之眼、血肉墙等）
  - 游戏进程（肉后、花后、石后、月后）
  - 时间（白天、晚上、中午、午夜）
  - 月相（满月、新月等 8 种）
  - 天气与事件（下雨、血月、日食、派对、沙尘暴、史莱姆雨等）
  - 入侵事件（哥布林军队、海盗入侵、霜月等）
  - 玩家所在生物群落（森林、丛林、沙漠、神圣、腐化等 20 余种）
  - 玩家最大生命值（<400 或 ≥400）
- **多商店配置**：支持配置多组商店，每组可设定启用状态、允许使用的用户组、进入/离开聊天消息等，方便针对不同玩家群体提供不同商品。
- **自动生成骷髅商人**：可启用自动生成，当满足条件（如击败某 Boss）时，骷髅商人会自动出现在城镇 NPC 附近。
- **手动召唤**：可使用 `/skeleton` 指令在任意坐标生成骷髅商人，也可使用特定物品（默认：坠落之星，ID 75）右键召唤。
- **重生机制**：骷髅商人被击杀后会按设定时间重生，并保留上次生成位置。
- **实时刷新**：商店内容可按设定间隔（毫秒）自动刷新，无需玩家重新对话。

## 指令
- `/skeleton <x> <y>` – 在指定坐标生成骷髅商人
- `/skeleton remove` – 移除当前已生成的骷髅商人

## 配置文件
配置文件位于 `tshock/SKShop.json`  
首次运行插件会自动生成默认配置，您可以根据注释修改。
